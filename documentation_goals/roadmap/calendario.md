## 📋 Checklist Diario

### Mañana (08:00)

```
□ Desayuno nutritivo (proteína + carbohidratos complejos)
□ Revisar calendario del día
□ 5 min: ¿Qué voy a lograr hoy en UTOP.IA?
```

### Trabajo (08:30-17:00)

```
□ Focus en trabajo principal
□ NO mezclar con UTOP.IA (separación mental)
□ Pausas cada 90 min
```

### UTOP.IA Session (17:00-20:00)

```
□ Revisar estado del sprint actual
□ 1 tarea principal (deep work)
□ 1-2 tareas secundarias si hay tiempo
□ Commit y push antes de cenar
□ Actualizar TODO.md del proyecto
```

### Noche (20:00-22:00)

```
□ Cena tranquila (sin pantallas)
□ Ejercicio o movimiento
□ Tiempo personal/social
□ Preparar ropa/cosas para mañana
```

### Antes de Dormir (22:00-00:00)

```
□ No código después de las 22:00
□ Lectura o contenido relajante
□ Planificar mañana (5 min)
□ Luces apagadas a las 00:00 máximo
```

## 🚦 Reglas de Oro

### 1. No Negociables

```
✅ 8 horas de sueño (00:00-08:00)
✅ Desayuno a las 08:00
✅ Cena a las 20:00
✅ Ejercicio diario (aunque sean 30 min)
✅ Al menos 1 commit diario en UTOP.IA
```

### 2. Flexibles pero Importantes

```
⚡ Las 3h de UTOP.IA pueden moverse (pero no eliminarse)
⚡ Fines de semana: más UTOP.IA, menos trabajo
⚡ Si hay evento social → sacrificar UTOP.IA de ese día, NO sueño
```

### 3. Prohibiciones

```
❌ Trabajar en UTOP.IA durante horario laboral
❌ Código después de las 22:00
❌ Saltarse comidas por programar
❌ Menos de 7h de sueño
❌ Más de 2 días seguidos sin ejercicio
```

## 💡 Recordatorios

> "El progreso consistente supera al esfuerzo esporádico."

- **3 horas diarias × 5 días = 15 horas semanales**
- **15 horas × 4 semanas = 60 horas mensuales**
- **60 horas × 12 meses = 720 horas anuales**

720 horas de desarrollo enfocado es suficiente para construir algo significativo.

> "No se trata de encontrar tiempo, se trata de hacer tiempo."

Protege tus 3 horas de UTOP.IA como si fueran una reunión inamovible.
